Experiment 01

Design a Simple Responsive Webpage

Aim

To design and develop a simple responsive webpage using HTML5 semantic elements, CSS3 Flexbox layout, and JavaScript for user interaction.

Algorithm

  1. Create the HTML5 document structure with viewport meta tag for responsive scaling.
  2. Define semantic layout elements: header, main, section, article, and footer.
  3. Use CSS Flexbox properties on the container (display: flex, justify-content: center, align-items: center).
  4. Apply a light-blue page background and dark-blue header background.
  5. Organize Aim, Algorithm, and Result content inside clean container blocks.
  6. Add JavaScript to display the live date and provide a contrast toggle.
  7. Provide an external college link and finish with a footer.

Result

The simple webpage has been successfully created and verified using HTML5, CSS3, and JavaScript.
